# 回复触发

## @触发

当bot被@时，等待input.merge_window秒。如果时间窗口内有新消息进入，则重新计算等待时间。如果时间窗口内进入的消息中有新@，则之前的消息立刻触发一次回复，新@进入等待窗口。

每次由@触发的回复应记录包含该@的确切消息，以便在回复时插入reply segment。

## 闲时触发

当群里沉默到达指定时间后，且最后一条消息不是bot的（包括@触发、闲时触发），则开始抽卡。每input.silence_wait_time分钟抽卡一次，input.reply_probability概率触发回复。

任何消息（包括bot自身的消息）将打破沉默和抽卡状态。闲时触发前，如有正在进行的回复，则取消该闲时触发和沉默状态

## 定时任务触发

通过 `input.scheduled_tasks` 为每个群配置任务数组。任务使用 Croner 调度，支持 5/6/7 字段 cron 表达式、nickname 和 `timezone`。只有同时位于 `group_whitelist` 的群会注册任务。

任务触发时，先向该群消息表插入一条 `special_type='system'` 的系统消息，内容为任务配置的 `prompt`，再以 `scheduled` 类型进入该群回复队列。若配置了 `deep_research_topic`，队列执行时会在第一轮回复前自动执行一次深度研究，并把研究开始/结束记录为系统消息。

## 注意事项

onebot不会收到bot自身的消息，需由我们进行处理
